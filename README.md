# 云叙石光 (Yunxu Shiguang)

&gt; 基于微信小程序的校园闲置物品信息服务平台  
&gt; A campus second-hand item information platform based on WeChat Mini Program

## 简介

「云叙石光」是面向中国石油大学（北京）在校学生的校内闲置物品信息展示与撮合平台。平台本身不参与线下交易，仅提供信息展示与撮合服务，致力于打通校园二手资源流通的"最后一公里"。

## 核心功能

- 🫧 **球形视图首页** — 物理引擎驱动的泡泡悬浮浏览
- 📦 **闲置转让** — 拍照发布，校内面交
- 🔍 **求购发布** — 精准撮合，让有货的人找你
- ✅ **实名认证** — 学生证审核，构建校园信任
- 🛡️ **先审后发** — 管理员审核，过滤垃圾信息

## 技术栈

- 前端：微信小程序原生框架 (WXML / WXSS / JavaScript)
- 后端：微信云开发 (Cloud Functions + Cloud Database + Cloud Storage)
- 安全：微信官方内容安全 API
