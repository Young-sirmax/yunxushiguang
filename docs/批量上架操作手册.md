# 批量上架 操作手册 v2（授权用户专用）

> 面向：被授权的「上架专员」与超级管理员
> 入口：小程序「我的」→「批量上架」（**仅授权账号可见**）
> 云函数：`adminBatch`（授权 / 导入 / 上架）、`config`（权限判定）
> v2 变更：**站内授权**取代控制台改白名单；**极简三步**取代 CSV + ZIP

---

## 一、授权（v2 起全部在小程序内完成）

v2 不再要求你去云开发控制台改 `admin_openids`。**超级管理员**在小程序里就能授权和回收。

### 1.1 谁是超级管理员

超管名单来自 `config` 集合 `key = "app"` 记录的 `super_admin_openids` 数组。
**该字段不存在或为空时，自动回退到既有的 `admin_openids`**——存量环境无需改配置即可平滑升级。

### 1.2 授权（两种方式）

**方式 A · 邀请卡（推荐，对方零操作）**

1. 超管：「我的」→「批量上架」→ **授权** Tab；
2. 填备注（选填，如「审核上架-张同学」）→ 点「**生成邀请卡**」；
3. 点「**转发邀请卡给 TA**」（或右上角「···」→「转发」），发给对方微信；
4. 对方点开 → 点「**接受授权**」→ 完成。全程不需要输入 openid、不需要先配置什么。

> 邀请卡 **5 分钟内有效，且只能被使用一次**。过期或被用了就重新生成一张。

**方式 B · 手动选人（对方不便点链接时）**

1. 授权 Tab → 在搜索框输入对方**昵称或姓名** → 点「搜索」；
2. 在结果里找到人 → 点「**授权**」。

### 1.3 被授权人怎么用

对方重新进入小程序（或等约 1 分钟），「我的」页就会出现「批量上架」入口，无需任何配置。

### 1.4 回收权限

授权 Tab →「已授权名单」→ 找到对应的人 → 点「**回收**」。

- 回收后对方入口消失（最长 1 分钟生效）；
- **对方已导入的「待上架」信息会保留**，由超管在「待上架」里处理；
- **被授权人不能转授他人**，只有超管能授权。

> ⚠️ 授权名单**不会下发到客户端**，`config.get` 只返回布尔值 `canBatch` / `isSuper`。

## 二、部署清单（首次使用需完成）

| 云函数 | 说明 |
|---|---|
| `adminBatch` | 已改造（新增授权、极简导入、批量上架）。依赖 `adm-zip`，**必须选「上传并部署：云端安装依赖」**，否则报 `Cannot find module 'adm-zip'` |
| `config` | 已改造（返回 `canBatch` / `isSuper`、支持 `super_admin_openids`）。**需重新部署** |

### 新建集合（v2 新增两个）

| 集合 | 用途 | 权限 | 索引 |
|---|---|---|---|
| `batch_admin` | 批量上架授权名单 | 所有用户不可读写 | `openid` 升序（普通索引） |
| `batch_invite` | 邀请卡一次性 token | 所有用户不可读写 | `token` 升序（普通索引） |

创建路径：云开发控制台 → 数据库 → 新建集合 → 建好后在「权限设置」选 **「所有用户不可读写」**，
再到「索引管理」添加上述索引（字段 + 升序，索引属性选**非唯一**）。

> 这两个集合**只由云函数读写**，前端不直连。权限设成「所有用户不可读写」即可，云函数不受此限制。

## 三、极简上架（**默认流程，日常就用这个**）

> 目标：拿着手机，在宿舍楼下 5 分钟把 20 件闲置挂上架。

### 三步

**① 选图** — 「批量上架」→ **极简上架** → 点「从相册选择 / 拍照」。
可多选、可多次追加，**单批上限 50 张**。每张自动压缩到 ≤500KB 后上传。

**② 填价** — 每张图是一张卡片，卡片上只有一个**价格**输入框。
- 不想逐张填？用「**批量填充价格**」一次填完；
- 价格可以**完全不填**，或用「**全部设为面议**」。没填价格的会按「价格面议」展示，不阻断上架。

**③ 上架** — 点底部「**确认导入（N）**」→ 全部落为**待上架** →
再点「**一键全部上架（N）**」→ 直接出现在首页。

> 标题**不用填**，系统自动生成（规则见第五节）。分类默认「其他闲置」。
> 底部「更多」信息（描述 / 成色 / 交易地点）**本流程不需要**，不影响上架。需要时可在「我的发布」里补充。

### 交互细节

- 每张图有**独立状态**：待上传 / 上传中 / 已上传 / 上传失败；
- **失败可单击「重试」单独重传**，不会整批回滚，也不会弹大弹窗打扰；
- **断点保护**：已选图片与已填价格会存在本地，退出小程序再进来不丢（保留 24 小时）；
- 全程不需要输入 openid、文件名、表头、分隔符。

---

## 四、待上架管理

- 列出封面、标题、价格、类型、分类；
- 「**上架**」→ 该条立即出现在首页（`draft` → `onSale`）；
- 「**全部上架（当前页）**」→ 一次请求批量上架当前页所有条目；
- 「**删除**」→ 删除该条**及其云存储图片**，不可恢复；
- 价格为「面议」的条目，价格文字用弱化色显示。

---

## 五、标题自动生成规则

极简模式不填标题时，按以下优先级生成（服务端执行，不在客户端自由发挥）：

1. **图片文件名是可读文本** → 直接用文件名（去扩展名，截断 ≤60 字）；
2. **否则** → `闲置 MMDD N/M`（例：`闲置 1008 3/12`，表示 10 月 8 日、第 3 件 / 共 12 件）。

> ⚠️ 实际使用中，**手机相册直选拿不到原始文件名**（`wx.chooseMedia` 不返回文件名），
> 所以规则 1 基本不会触发，日常都会走规则 2。规则 1 只在数据里带了文件名时生效（如高级模式）。
>
> 上架后可在「我的发布」里改标题。

## 六、高级模式：表格导入（桌面场景）

> 手机端**不需要**用这个。入口在「批量上架」→ **高级** Tab，默认不露出。

### 6.1 CSV 模板

**表头**（第一行，UTF-8 保存）：

```csv
title,description,price,category,type,image_filename1,image_filename2,image_filename3,image_filename4,image_filename5,image_filename6
```

**示例数据**：

```csv
title,description,price,category,type,image_filename1,image_filename2,image_filename3,image_filename4,image_filename5,image_filename6
出售 九成新 iPad 2021,自用一年无磕碰，含原装充电器,1450,数码电子,sell,ipad_1.jpg,ipad_2.jpg,,,,
求购 高等数学 上册,同济第七版，笔记完整即可,30,书籍教材,want,,book.jpg,,,,
出 山地自行车 可小刀,骑行半年，链条刚换过,380,其他闲置,sell,bike_1.jpg,bike_2.jpg,bike_3.jpg,,,
以物换物 想换一副羽毛球拍,球拍成色不限，可补差价,0,其他闲置,exchange,racket.jpg,,,,,
高中数学一对一辅导,高考数学 140+，可线上可线下,120,技能服务,skill,,,,,,
```

**列说明**：

| 列名 | 必填 | 说明 |
|---|---|---|
| `title` | ✅ | 标题，≤60 字 |
| `description` | | 描述（走内容安全检测） |
| `price` | 见下 | 数字。`sell` 必须 > 0（**留空会失败**，与极简模式不同）；求购/以物易物忽略；技能服务选面议时可留空 |
| `category` | | 分类**名称**（如「数码电子」「书籍教材」），系统自动匹配 `categoryId` |
| `type` | | `sell`（闲置，默认）/ `want`（求购）/ `exchange`（以物易物）/ `skill`（技能服务） |
| `image_filename1~6` | | 图片文件名，与 zip 内文件名对应；最多 6 张 |
| `condition` | | 选填，成色 |
| `tradeLocation` | | 选填，交易地点 |
| `price_unit` | | 选填，仅技能服务：`per_time` / `per_hour` / `negotiable` |
| `exchange_want` | | 选填，仅以物易物：期望交换物；留空用标题兜底 |

> 列名大小写不敏感、顺序不限；多余列会被忽略。

### 6.2 图片压缩包要求

- 格式 **zip**，内部为 jpg / jpeg / png / webp / gif / bmp；
- **文件名需与 CSV 的 `image_filename` 列一致**；
- 匹配规则**很宽松**：忽略大小写、扩展名、空格/下划线/横线/括号。
  例：CSV 写 `ipad_1.jpg`，zip 里是 `IPAD 1.JPG` 也能匹配上；
- **单次最多处理 120 张**（超出会提示拆分后再传）；
- 建议 zip 内文件用**英文/数字命名**：Windows 自带压缩在某些编码下会把中文名压成乱码，导致匹配不到。

### 6.3 操作流程

1. 把 CSV 和 zip 先发到微信「**文件传输助手**」（小程序只能从聊天记录里选文件）；
2. 「高级」→ **表格导入** → 点「① 选择 CSV」→ 页面解析并显示行数；
3. 点「② 选择 ZIP」→ 自动上传并解压；
4. 页面按行匹配图片，显示 `图片 N 张` / **`图片缺失`** / `无图`（缺失行可点「跳过此行」）；
5. 点「③ 开始导入」→ 完成后弹窗显示成功/失败条数；
6. 有失败行时点「**重试失败行**」只重跑这些行；
7. 切到 **待上架** Tab → 确认后上架。

### 6.4 手动录入（量少时）

「高级」→ **手动录入** → 选图、填标题/类型/分类/价格/描述 → 「提交到待上架」。

> v2 起价格**允许留空**（留空按「价格面议」展示）。

## 七、规则与边界

| 事项 | 规则 |
|---|---|
| 导入后的状态 | `status = 'draft'`（**待上架**），不出现在首页；也不在管理员「商品审核」待审列表里（那是普通用户的 `pendingReview` 流程） |
| 「我的发布」 | 待上架条目会显示在「我发布的信息」中，状态标签为**待上架** |
| 发布频率限制 | **批量导入不走** 1 分钟 1 条 / 1 天 10 条的限制 |
| 内容安全检测 | **每条仍然检测**：标题、描述走 `msgSecCheck`；每张图片走 `imgSecCheck`。不通过则该条失败并给出原因 |
| 归属字段 | `owner` = 当前操作者 openid；`operator` = 实际操作者 openid；`_openid` 同步为 owner |
| 一次性导入量 | 极简模式单批 ≤50 张；CSV 单次提交 ≤50 行（自动分批）；zip 单次 ≤120 张图 |
| 一次性上架量 | `publishBatch` 单次 ≤50 条 |
| 维护模式 | 本页顶部有说明位：`config.maintenance = true` 时全站写操作被拒，操作前请确认未开启维护 |

## 八、常见问题

| 现象 | 原因与处理 |
|---|---|
| 看不到「批量上架」入口 | 未被授权。让超管在「授权」Tab 里开通；授权后约 1 分钟生效 |
| 看不到「授权」Tab | 你不是超管。超管名单在 `config.super_admin_openids`（缺失时回退 `admin_openids`） |
| 生成邀请卡报错 | `batch_invite` 集合没建，见第二节 |
| 对方点邀请卡提示「已过期」/「已被使用」 | 邀请卡 5 分钟有效且只能用一次，重新生成一张 |
| 报 `Cannot find module 'adm-zip'` | `adminBatch` 部署时没选「云端安装依赖」，重新部署 |
| 提示「无批量上架权限」 | 未被授权，或被回收了，联系超管 |
| 极简模式某张图一直「上传失败」 | 单击该卡片的「重试」单独重传；仍失败就「移除」后重新选这张 |
| 标题显示成「闲置 1008 3/12」 | 相册直选拿不到文件名，走了自动生成规则。上架后可在「我的发布」里改 |
| 提示「压缩包解析失败」 | 不是标准 zip，或扩展名伪装；用系统自带压缩重新打包 |
| 大量「图片缺失」 | zip 内文件名与 CSV 不一致，或中文名乱码；改英文名重传 |
| 提示「标题超过 60 字」 | 缩短标题后重试（该行会在失败明细里） |
| 提示「价格必须大于 0」 | 这是**高级模式（CSV）**的 sell 行，CSV 里 `price` 必须填。极简模式不填价格不会报这个 |
| 提示某条「包含违规信息」 | 内容安全检测未通过，修改文案/图片后重试 |
| 导入成功但首页看不到 | 还是 `draft` 状态，需到「待上架」Tab 点「上架」 |

## 九、后续「收费代上架」可复用的点

- **归属**：`owner` / `operator` 已分离，后续可把 `owner` 记为发布者 openid、`operator` 记为运营人员，用于计费与审计；
- **批次**：每条都带 `importBatchId`，可按批次统计与回溯；
- **授权**：`batch_admin` 按 openid 开通并可随时回收，天然支持「只给付费代上架账号开放」；
- **留痕**：`batch_admin` 记录了 `grantedBy` / `grantTime` / `revokedBy` / `revokeTime` / `grantedVia`，可追溯授权链路。
