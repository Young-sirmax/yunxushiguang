# 批量上架 操作手册（管理员专用）

> 面向：需要为他人代上架（后续收费代上架业务）的管理员
> 入口：小程序「我的」→「批量上架」（**仅白名单账号可见**）
> 云函数：`adminBatch`（解压/导入/待上架）、`config`（白名单判定）

---

## 一、开通权限（**唯一需要你手动配置的事项**）

批量上架不看 `isAdmin`，只看 **config 集合里的白名单数组**。

1. 云开发控制台 → 数据库 → `config` 集合 → 找到 `key = "app"` 的记录 → 编辑；
2. 加入（或修改）`admin_openids` 字段（**数组**，元素为管理员的 openid）：

```json
{
  "key": "app",
  "maintenance": false,
  "notice": "系统维护中，请稍后再试",
  "admin_openids": ["oXXXXXXXXXXXXXXXXXXXXXXXXXXX", "oYYYYYYYYYYYYYYYYYYYYYYYYYYY"]
}
```

3. 保存即可（**无需重新部署**，最长 5 分钟生效；客户端有 5 分钟配置缓存）。

**怎么拿到自己的 openid？**
- 方式一：云开发控制台 → 数据库 → `user` 集合 → 找到自己那条记录 → 复制 `_openid` 字段；
- 方式二：小程序内先正常登录一次，控制台按昵称搜索定位。

> ⚠️ 白名单**不会下发到客户端**（`config.get` 只返回"当前调用者是否有权限"的布尔值 `canBatch`），避免泄露。
> ⚠️ 所有 `adminBatch` 操作第一步都校验白名单，不在名单内一律返回「无批量上架权限」。

## 二、部署清单（首次使用需完成）

| 云函数 | 说明 |
|---|---|
| `adminBatch` | **新增**，含依赖 `adm-zip`（用于解压 zip）。**必须选「上传并部署：云端安装依赖」**，否则会报 `Cannot find module 'adm-zip'` |
| `config` | 已改造，返回 `canBatch`；需重新部署 |

新建/已有的 `config` 集合记录见第一节。

## 三、CSV 模板

### 表头（第一行，UTF-8 保存）

```csv
title,description,price,category,type,image_filename1,image_filename2,image_filename3,image_filename4,image_filename5,image_filename6
```

### 示例数据

```csv
title,description,price,category,type,image_filename1,image_filename2,image_filename3,image_filename4,image_filename5,image_filename6
出售 九成新 iPad 2021,自用一年无磕碰，含原装充电器,1450,数码电子,sell,ipad_1.jpg,ipad_2.jpg,,,,
求购 高等数学 上册,同济第七版，笔记完整即可,30,书籍教材,want,,book.jpg,,,,
出 山地自行车 可小刀,骑行半年，链条刚换过,380,其他闲置,sell,bike_1.jpg,bike_2.jpg,bike_3.jpg,,,
以物换物 想换一副羽毛球拍,球拍成色不限，可补差价,0,其他闲置,exchange,racket.jpg,,,,,
高中数学一对一辅导,高考数学 140+，可线上可线下,120,技能服务,skill,,,,,,
```

### 列说明

| 列名 | 必填 | 说明 |
|---|---|---|
| `title` | ✅ | 标题，≤60 字。气泡短标题会自动清洗生成（见《气泡关键字符规则》相关实现） |
| `description` | | 描述（走内容安全检测） |
| `price` | 闲置必填 | 数字。**闲置转让必须 > 0**；求购/以物易物忽略；技能服务选面议时可留空 |
| `category` | | 分类**名称**（如「数码电子」「书籍教材」），系统会自动匹配 `categoryId`，让首页分类筛选可用 |
| `type` | | `sell`（闲置，默认）/ `want`（求购）/ `exchange`（以物易物）/ `skill`（技能服务） |
| `image_filename1~6` | | 图片文件名，与 zip 内文件名对应；最多 6 张 |
| `condition` | | 选填，成色（如 `9成新`） |
| `tradeLocation` | | 选填，取货/交易地点 |
| `price_unit` | | 选填，仅技能服务：`per_time` / `per_hour` / `negotiable` |
| `exchange_want` | | 选填，仅以物易物：期望交换物；留空时会自动用标题兜底 |

> 列名大小写不敏感、顺序不限；多余列会被忽略。

## 四、图片压缩包要求

- 格式 **zip**，内部为 jpg / jpeg / png / webp / gif / bmp；
- **文件名需与 CSV 的 `image_filename` 列一致**；
- 匹配规则**很宽松**：忽略大小写、忽略扩展名、忽略空格/下划线/横线/括号。
  例：CSV 写 `ipad_1.jpg`，zip 里是 `IPAD 1.JPG` 也能匹配上；
- **单次最多处理 120 张**（超出会提示拆分后再传）；
- 建议 zip 内文件用**英文/数字命名**：Windows 自带压缩在某些编码下会把中文名压成乱码，导致匹配不到（此时页面会明确标出"图片缺失"）。

## 五、操作流程

### A. 表格 + 图片包导入（推荐）

1. 把 CSV 和 zip 先发到微信「**文件传输助手**」（小程序只能从聊天记录里选文件）；
2. 「我的」→「批量上架」→ **表格导入**；
3. 点 **① 选择 CSV** → 选刚发的 CSV → 页面解析并显示行数；
4. 点 **② 选择 ZIP** → 选图片包 → 自动上传并解压（会提示成功张数）；
5. 页面按行匹配图片，显示：`图片 N 张` / **`图片缺失`** / `无图`；
   - 图片缺失的行可以点「**跳过此行**」，或保留（无图导入）；
6. 点 **③ 开始导入** → 进度条走到 100% → 弹窗显示成功/失败条数；
7. 有失败行时，下方「**失败明细**」会列出「第几行 + 具体错误」，点「**重试失败行**」可只重试这些行；
8. 切到 **待上架** Tab → 确认后逐条「**上架**」，或点「**全部上架（当前页）**」。

### B. 手动录入（量少时）

1. 「批量上架」→ **手动录入**；
2. 选图片（相册/拍摄，自动压缩到 ≤500KB）→ 填标题、类型、分类、价格、描述；
3. 点「**提交到待上架**」→ 去 **待上架** Tab 上架。

### C. 待上架管理

- 列表显示封面、标题、价格、类型、分类、来源行号；
- 「上架」→ 该条立即出现在首页（状态由 `draft` 变为 `onSale`）；
- 「删除」→ 删除该条**及其云存储图片**，不可恢复。

## 六、规则与边界

| 事项 | 规则 |
|---|---|
| 导入后的状态 | `status = 'draft'`（**待上架**），不出现在首页；也不出现在管理员「商品审核」待审列表里（那是普通用户的 `pendingReview` 流程） |
| 「我的发布」 | 待上架条目会显示在「我发布的信息」中，状态标签为**待上架** |
| 发布频率限制 | **批量导入不走** 1 分钟 1 条 / 1 天 10 条的限制 |
| 内容安全检测 | **每条仍然检测**：标题、描述走 `msgSecCheck`；每张图片走 `imgSecCheck`。不通过则该行失败并给出原因 |
| 归属字段 | `owner` = 管理员 openid；`operator` = 实际操作者 openid；`_openid` 同步为 owner，保证详情页联系方式/头像正确显示 |
| 一次性导入量 | 单次提交最多 50 行（页面会自动分批），zip 单次最多 120 张图 |
| 维护模式 | 本页顶部有说明位：`config.maintenance = true` 时全站写操作被拒（`adminBatch` 的导入/上架同样会被拦截），操作前请确认未开启维护 |

## 七、常见问题

| 现象 | 原因与处理 |
|---|---|
| 报 `Cannot find module 'adm-zip'` | `adminBatch` 部署时没选「云端安装依赖」，重新部署 |
| 提示「无批量上架权限」 | 你的 openid 不在 `config.admin_openids` 里，按第一节添加 |
| 提示「压缩包解析失败」 | 不是标准 zip，或扩展名伪装；用系统自带压缩重新打包 |
| 大量「图片缺失」 | zip 内文件名与 CSV 不一致，或中文名乱码；改英文名重传，或用宽松命名（去掉下划线、空格） |
| 提示「标题超过 60 字」 | 缩短标题后重试（该行会在失败明细里） |
| 提示「价格必须大于 0」 | `type=sell` 的行必须填价格 |
| 提示某条「包含违规信息」 | 内容安全检测未通过，修改文案/图片后重试 |
| 导入成功但首页看不到 | 它们还是 `draft` 状态，需到「待上架」Tab 点「上架」 |

## 八、后续「收费代上架」可复用的点

- **归属**：`owner` / `operator` 已分离，后续若由运营人员代客上架，可把 `owner` 记为发布者 openid、`operator` 记为运营人员，用于计费与审计；
- **批次**：每条都带 `importBatchId`，可按批次统计与回溯；
- **白名单**：按 openid 开通，天然支持"只给付费代上架账号开放"。
