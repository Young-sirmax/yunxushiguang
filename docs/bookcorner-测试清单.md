### 小程序端联调自测（真正验证登录态与写入）

1. 首页 → 「我的」→ 「公益图书角」→ 进入主页，能看到空间名与 A/B 两个分区卡片。
2. 进 A 区列表 → 应看到 3 本种子书；点任意一本进详情。
3. 详情页底部输入「测试留言」→ 提交 → 提示「留言已提交，将在审核后展示」。
4. 云开发控制台 → 数据库 → `book_comment`：应新增 1 条，`status` 为 `approved`（未命中敏感词时）或 `pending`（命中时），`nickname` 来自 user 集合、`userId` 是 user._id。
5. 重新进详情页 → 只有 `approved` 的留言会显示；`pending` 不显示。
6. 输入含「加微信」的留言 → 提交成功但**不显示**（进了待审）。

## 二、云函数 commentReview（指令 3）

### 已完成的本地自测
`node tests/commentReview.local.test.js` → **26 项全通过**，重点覆盖权限不可绕过：

| 场景 | 结果 |
|---|---|
| 普通用户读待审列表 / 通过留言 | `无权限` |
| 普通用户越权审核其他空间的留言 | `无权限`，且目标留言状态不变 |
| `user.isAdmin === true` | 放行（平台管理员） |
| `user.role === 'admin'` | 放行 |
| `role=space_manager` 且在本空间 managers 内 | 放行，仅限本空间 |
| 在 managers 内但没有 role 字段 | 拒绝（双条件） |
| 审核成功 | 写 `op_log`（含 operatorId / operatorRole / action / targetId） |

| # | 用例 | 预期 |
|---|---|---|
| 1 | 非管理员打开 `/pages/admin/admin` 并进入「留言审核」 | 列表为空/提示无权限，不泄露数据 |
| 2 | 管理员登录后看模块栏 | 「留言审核」右侧出现待审数量角标；处理完待审后角标自动刷新 |

| 8 | 分页 | 待审超过 20 条时底部出现「加载更多」，点击后追加；加载完显示「已加载全部」 |

| 10 | 操作留痕 | 每次通过/拒绝/加精后，控制台 `op_log` 集合新增一条对应记录 |

## 四、用户端页面（指令 5 / 6）

### 主页 `pages/bookcorner/index`
| 用例 | 预期 |
|---|---|
| 正常进入 | 顶部渐变头图 + 空间名；两个分区卡片（A区·教材流转 / B区·馆内阅览）；底部小字「本功能由云叙石光提供技术支持」 |
| 空间不存在 | toast 提示，页面仍可点分区卡片 |
| 点击分区卡片 | 跳 `list?zone=A` / `list?zone=B`，导航栏标题随分区变化 |

### 书目列表 `pages/bookcorner/list`
| 用例 | 预期 |
|---|---|
| 有数据 | 卡片：书名加粗一行 + 右侧分类胶囊 + 简介前 40 字；`intro` 为空则只有书名+分类 |
| 分类筛选 | 顶部横向分类可点，切换后列表重置为该分类 |
| 空列表 | 空态图标 + 「这里还没有书」+ 分区提示文案 |
| 下拉刷新 | 列表回到第一页并刷新 |
| 触底分页 | 第 2 页追加，加载完显示「没有更多了」 |
| A 区额外入口 | 底部出现「拿一本，留一本 · 去登记换书」 |
| 网络失败 | toast「加载失败，请稍后重试」，不白屏 |

### 书详情 + 留言 `pages/bookcorner/detail`
| 用例 | 预期 |
|---|---|
| 正常 | 书名/分类/作者/简介（空则不显示简介区）+「N 条留言」 |
| 留言列表 | 只显示已通过留言；精选留言置顶且带「精选」小标；其余按时间正序（老的在前） |
| 未登录点输入栏 | 弹「需要登录」→ 点确定跳 `/pages/index/index` |
| 提交留言 | toast「留言已提交，将在审核后展示」（无论直接通过还是待审，文案一致） |
| 超长 | 输入框限制 200 字，服务端再截断一次 |
| 分页 | 触底加载更多，重复 20 条一页 |

### 换书登记 `pages/bookcorner/exchange`
| 用例 | 预期 |
|---|---|
| 未登录提交 | 弹登录引导 |
| 缺字段 | toast「请填写要带走的书名」/「请填写要留下的书名」 |
| 字数统计 | 两个输入框实时显示 `n/50`，超过 50 字自动截断 |
| 昵称 | 只读展示，取当前用户昵称 |
| 提交成功 | 显示成功页：「登记成功，让文字继续旅行」+ 转化钩子按钮 |
| 10 分钟内重复提交 | 不重复写流水，仍返回成功（幂等） |
| 转化钩子 | 点击跳发布页并携带 `from=bookcorner`，同时本地写入 `publishFrom=bookcorner` |
