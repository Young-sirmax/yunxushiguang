# 云叙石光 · UI 专业评审（阶段 3 · 第一轮）

> 评审视角：顶级小程序 UI 设计师
> 评审范围：`miniprogram/` 全部 30 个页面 + 全局设计系统 `app.wxss`
> **约束（用户指定）：不做大刀阔斧的风格改动，整体主色保持青绿 `#00c17e` 体系**
> 方法：先做数据化扫描（硬编码颜色 / 字号 / 空态 / 导航风格），再给结构层结论

## 一、总体结论

设计系统本身是**健康**的：`app.wxss` 里颜色、圆角、阴影、按钮、空态、输入框全部变量化，主色渐变（薄荷绿→青绿→湖水青）统一，卡片用 Material 3 式双层阴影，整体是"青春校园 · 活力青绿"的一致调性。

问题不在"风格"，而在**执行度**：越早写的页面（发布页、我的页）越多硬编码颜色和字号，越新的页面（图书角）越规范——说明规范是后来才形成的，老页面没有回头对齐。

## 二、🔴 优先修（影响一致性与后期维护成本）

1. **主色被写死在 4 个 wxss 里**：`commodity_release.wxss`（102 处硬编码色值）、`home.wxss`（68 处）、`admin_batch.wxss`（39 处）、`home_about.wxss`（36 处）。
   风险：将来微调主色（比如为了印刷物料做微调）时，这些页面不会跟随，会出现"两种绿"。
   建议：把硬编码值逐条替换为 `var(--primary)` / `var(--primary-grad)` / `var(--primary-soft)`，一次改完，视觉零变化。

2. **发布页 `commodity_release` 是全站颜色最杂的页面**（102 处）。
   建议：优先处理它，它同时是用户停留最久、最容易被截图传播的页面。

3. **页面导航风格不统一**：只有 `commodity_list`、`home`、`index` 用自定义导航（`navigationStyle: custom` + 自绘渐变头），其余 27 个页面用系统导航栏。
   结果：从首页点进二级页时，顶部会从"渐变头 + 无返回"突然变成"绿色系统栏 + 返回箭头"，有割裂感。
   建议（二选一，不要混）：① 全面系统栏，把首页也统一；② 把二级页都换成同款渐变头。**图书角模块目前跟随系统栏，是可接受的折中**。

## 三、🟡 建议修（体验细节）

4. **小字号偏多**：`admin.wxss`、`admin_batch.wxss`、`commodity_detail.wxss`、`commodity_search.wxss`、`commodity_release.wxss` 等出现大量 `font-size: 20rpx`（最新一处：`miniprogram/pages/bookcorner/detail.wxss:122` 的「精选」小标）。
   建议：**正文类**最小 24rpx，**标签/角标类**可保留 20rpx（当前的 20rpx 基本都用在标签上，属可接受；但要避免用在说明文字上）。
   自查点：`admin.wxss:704` 的 19rpx 明显偏小，建议提到 22rpx。

5. **部分页面缺空态**：`business.wxml`、`expert_apply.wxml`、`home_feedback.wxml`、`home_user_info.wxml` 等在"没有数据"时不显示任何引导。
   反例（做得好）：`home_favorite.wxml` 有空态图标 + 文案 + 行动按钮，是全站标准。
   建议：按 `home_favorite` 的四件套（图标 / 主文案 / 辅助文案 / 主按钮）补齐。

6. **按钮层级**：列表页卡片里的操作按钮（`.mini-btn`）和主操作按钮（`.btn-primary`）视觉权重接近，长列表里容易误触。
   建议：危险操作（删除/封禁）保持描边或浅底，主操作才用实色渐变。

7. **加载态表达单一**：全站几乎都用文字「加载中...」，没有骨架屏。
   建议（低成本）：至少给首页与图书角列表加 3 条灰色占位卡，观感提升明显。

## 四、🔵 可选优化（锦上添花）

8. **图书角新模块可加"分区主题色"**：当前 A/B 分区用卡片徽章字母区分（A 青绿、B 蓝），信息量足够但记忆点不强。
   建议：A 区沿用主色青绿，B 区沿用技能蓝（`--skill`），并在列表页头部渐变色上做同色系呼应——**不引入新色**，完全在现有变量内。

9. **留言长帖的"接力感"可以更强**：现在是白卡列表 + 精选置顶。
   建议：给留言卡左侧加一条 4rpx 的主色竖线（时间轴隐喻），首条加"开帖"标记，成本极低、情绪价值高。

10. **入口图标规范**：`images/bookcorner-entry.png` 目前是占位图（青绿圆角块 + 白色书页 + 黄色书签，144×144）。
    替换茶咖 logo 时请保持：正方形、≥144×144、圆角约 24%、无文字、深色底上也能看清（建议带白色描边或浅底）。

11. **深色模式**：全站变量集中在 `app.wxss` 的 `page` 选择器，未来要支持深色模式只需加一段 `@media (prefers-color-scheme: dark)` 覆盖变量——这是现有架构最大的红利，建议保留这个写法不要退化。
