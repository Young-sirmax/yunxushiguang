# 设计规范（扫描现有小程序页面得出）

> 扫描范围：`miniprogram/app.wxss`（全局设计系统）+ 现有 32 个页面
> 主基调：青春校园风 · 活力青绿

## 一、颜色（全部走 CSS 变量，定义在 `miniprogram/app.wxss` 的 `page` 选择器）

| 变量 | 值 | 用途 |
|---|---|---|
| `--primary` | `#00c17e` | 主色（活力青绿） |
| `--primary-dark` | `#00a76b` | 主色加深（按压/文字） |
| `--primary-light` / `--primary-soft` | `#e0f8ef` | 主色浅底（标签、图标底） |
| `--primary-grad` | `135deg, #3be6ad → #00c17e → #00b3a3` | 主渐变（按钮、图标块） |
| `--primary-grad-vivid` | `160deg, #3ce8b2 → #00c17e → #00a9c4` | 头部大块渐变 |
| `--accent` | `#ff7a59` | 强调色（珊瑚橙） |
| `--sun` | `#ffc53d` | 点缀色（阳光黄） |
| `--text` / `--text-secondary` / `--text-light` | `#0f1b2d` / `#5a6b7f` / `#94a3b8` | 三级文字 |
| `--bg` / `--bg-card` / `--border` | `#f5f7fa` / `#ffffff` / `#eef1f5` | 背景、卡片、描边 |
| `--warning` / `--danger` / `--info` | `#ffb020` / `#f43f5e` / `#3b82f6` | 功能色 |

> 图书角模块允许另起一套**分区主题色**（A区/B区各一色），但必须从现有色板里取，不得引入新色系。

## 二、圆角 / 阴影 / 间距

- 圆角：`--radius: 20rpx`（控件）、`--radius-lg: 28rpx`（卡片）、`--radius-pill: 999rpx`（胶囊按钮）。
- 阴影：`--shadow-sm`（弱）、`--shadow-card`（卡片）、`--shadow-primary`（主色按钮发光）。
- 页面内边距：`24rpx`（`.container`）；卡片内边距 `28rpx`；卡片间距 `24rpx`。

## 三、组件样式（全局类，直接复用，不重写）

| 类名 | 说明 |
|---|---|
| `.card` | 白底 + 28rpx 圆角 + 双层阴影 + 28rpx 内边距 |
| `.btn-primary` | 胶囊形渐变主按钮，高 92rpx，带顶部高光与按压反馈 |
| `.input-base` | 高 88rpx 输入框，`#f1f5f9` 底，聚焦时主色描边 + 光晕 |
| `.section-title` / `.section-title.title-bar` | 区块标题；加 `title-bar` 出左侧绿色竖条 |
| `.empty-state` / `.empty-icon-wrap` / `.empty-text` / `.empty-hint` | 空态：圆形浅绿底图标 + 标题 + 灰色提示 |
| `.loading-tip` / `.no-more` | 列表加载提示 / 到底提示 |
| `.flex-between` / `.flex-center` / `.text-secondary` / `.text-light` / `.mt-24` 等 | 布局与文本工具类 |

## 四、页面结构约定

- 首页类页面用 `navigationStyle: custom` + 自绘渐变头部（`--primary-grad-vivid`，底部圆角 40rpx）。
- 列表页统一：下拉刷新（`onPullDownRefresh`，在 `.json` 里开 `enablePullDownRefresh`）+ 触底加载（`onReachBottom` 或 `bindscrolltolower`）+ 空态 + 加载态 + `没有更多了`。
- 列表项点击 → `wx.navigateTo` 到详情页；详情页返回用系统返回。
- 轻提示统一 `wx.showToast`（`wx.showToast({ title, icon: 'none' })`），加载用 `wx.showLoading` / `wx.hideLoading`。

## 五、目录与命名

- 页面：`miniprogram/pages/<模块名>/<模块名>.{js,json,wxml,wxss}`，四个文件同名。
- 路由命名：下划线小写（`commodity_list`）；图书角模块统一用 `bookcorner` 前缀（`pages/bookcorner/index`、`pages/bookcorner/list`…）。
- 公共方法放 `miniprogram/utils/`，接口封装统一加到 `miniprogram/api/api.js` 的 `API` 对象里（**不在页面里直接 `wx.cloud.callFunction`**）。
- 图片资源放 `miniprogram/images/`，tabbar 图标放 `miniprogram/images/tabbar/`。

## 六、文案语气

- 面向学生，口语化、简短、有温度（例："让文字继续旅行"）。
- 不暴露技术细节与审核机制（如留言审核统一提示「留言已提交，将在审核后展示」，不写"命中敏感词"）。
