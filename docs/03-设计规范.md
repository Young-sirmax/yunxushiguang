# 设计规范（扫描现有小程序页面得出）

> 扫描范围：`miniprogram/app.wxss`（全局设计系统）+ 现有 32 个页面
> 主基调：青春校园风 · 活力青绿

## 一、颜色（全部走 CSS 变量，定义在 `miniprogram/styles/theme.wxss` 的 `page` 选择器）

> **色板唯一来源**：`miniprogram/styles/theme.wxss`（由 `app.wxss` 首行 `@import` 引入）。
> 页面与组件里**禁止再写十六进制 / 裸 rgb()**。完整的「旧色值 → 令牌」对照表见
> 《06-色板对照表.md》。

### 主色 / 价格 / 中性（最常用）

| 令牌 | 值 | 用途 |
|---|---|---|
| `--primary` | `#22B07D` | 主色：顶部导航、按钮、选中态、认证标签 |
| `--primary-dark` | `#14915F` | 主色深：按下态、浅底上的强调文字 |
| `--primary-light` | `#E9F7F0` | 主色浅底：选中底、标签底、图标底 |
| `--primary-grad` / `--primary-grad-vivid` | 同色相三段绿 | 主渐变（按钮）/ 头部大块渐变 |
| `--price` | `#F5402F` | 价格色：全站唯一（卡片价、详情价、求购预算） |
| `--price-soft` / `--price-grad` | `#FDECEB` / 红渐变 | 价格浅底 / 优惠角标渐变 |
| `--text` / `--text-secondary` / `--text-light` | `#1F2329` / `#646A73` / `#9AA0A6` | 文字主 / 次 / 弱 |
| `--bg` / `--bg-card` / `--border` / `--fill` / `--fill-strong` | `#F6F7F9` / `#FFFFFF` / `#EFF0F2` / `#EFF0F2` / `#E4E6EA` | 背景 / 卡片 / 分割线 / 控件填充 / 骨架 |

### 语义色（各带浅底与「深档」）

| 令牌 | 值 | 用途 |
|---|---|---|
| `--success` / `--success-soft` / `--success-dark` | `#22B07D` / `#E9F7F0` / `#14915F` | 成功（与主色同源）：已认证 |
| `--warning` / `--warning-soft` / `--warning-dark` | `#F5A623` / `#FFF6E6` / `#B45309` | 警告：审核中、交易状态、星级、提示 |
| `--error` / `--error-soft` / `--error-grad` | `#F5402F` / `#FDECEB` / 红渐变 | 错误（与价格色同源）：删除、封禁、危险按钮 |
| `--info` / `--info-soft` | `#4C86D9` / `#EBF3FF` | 信息（与技能色同相） |

> **浅底上的文字必须用深档**：`--warning` 直接压在 `--warning-soft` 上对比度只有 1.9，
> 小字读不出来。同理用 `--success-dark`、`--type-*-text`。

### 类型色（气泡渐变 + 卡片角标共用同一组）

| 类型 | from → to | text（浅底上的文字） | soft |
|---|---|---|---|
| 闲置 idle | `#7EE8C7` → `#4ECDC4` | `#0E8C7C` | `#E6F7F2` |
| 以物易物 exchange | `#FFD194` → `#FFB37B` | `#C4763C` | `#FFF4E9` |
| 求购 wanted | `#C9BEFF` → `#A78BFA` | `#7B5BD6` | `#F1ECFE` |
| 技能服务 skill | `#A1C4FD` → `#7FB3FF` | `#4C86D9` | `#EBF3FF` |

每类各有 `--type-<key>-grad` 直接用；求购二级分区「技能求助」另有一档加深色
`--type-wanted-deep`。**四类之外禁止新增色相。**

> 图书角模块允许另起一套**分区主题色**（A区/B区各一色），但必须从现有色板里取，不得引入新色系。
> canvas（气泡绘制）读不到 CSS 变量，`utils/theme.js` 的 `TOKENS` / `TYPE_THEME` 是
> canvas 侧的镜像，**改色必须两处同步**。

## 二、圆角 / 阴影 / 间距

- 圆角：`--radius: 20rpx`（控件）、`--radius-lg: 28rpx`（卡片）、`--radius-pill: 999rpx`（胶囊按钮）。
- 阴影：`--shadow-sm`（弱）、`--shadow-card`（卡片）、`--shadow-primary`（主色按钮发光）。
- 页面内边距：`24rpx`（`.container`）；卡片内边距 `28rpx`；卡片间距 `24rpx`。

## 三、组件样式（全局类，直接复用，不重写）

| 类名 | 说明 |
|---|---|
| `.card` | 白底 + 28rpx 圆角 + 双层阴影 + 28rpx 内边距 |
| `.btn-primary` | 胶囊形渐变主按钮，高 92rpx，带顶部高光与按压反馈 |
| `.input-base` | 高 88rpx 输入框，`#f1f5f9` 底，聚焦时主色描边 + 光晕 |
| `.section-title` / `.section-title.title-bar` | 区块标题；加 `title-bar` 出左侧绿色竖条 |
| `.empty-state` / `.empty-icon-wrap` / `.empty-text` / `.empty-hint` | 空态：圆形浅绿底图标 + 标题 + 灰色提示 |
| `.loading-tip` / `.no-more` | 列表加载提示 / 到底提示 |
| `.flex-between` / `.flex-center` / `.text-secondary` / `.text-light` / `.mt-24` 等 | 布局与文本工具类 |

## 四、页面结构约定

- 首页类页面用 `navigationStyle: custom` + 自绘渐变头部（`--primary-grad-vivid`，底部圆角 40rpx）。
- 列表页统一：下拉刷新（`onPullDownRefresh`，在 `.json` 里开 `enablePullDownRefresh`）+ 触底加载（`onReachBottom` 或 `bindscrolltolower`）+ 空态 + 加载态 + `没有更多了`。
- 列表项点击 → `wx.navigateTo` 到详情页；详情页返回用系统返回。
- 轻提示统一 `wx.showToast`（`wx.showToast({ title, icon: 'none' })`），加载用 `wx.showLoading` / `wx.hideLoading`。

## 五、目录与命名

- 页面：`miniprogram/pages/<模块名>/<模块名>.{js,json,wxml,wxss}`，四个文件同名。
- 路由命名：下划线小写（`commodity_list`）；图书角模块统一用 `bookcorner` 前缀（`pages/bookcorner/index`、`pages/bookcorner/list`…）。
- 公共方法放 `miniprogram/utils/`，接口封装统一加到 `miniprogram/api/api.js` 的 `API` 对象里（**不在页面里直接 `wx.cloud.callFunction`**）。
- 图片资源放 `miniprogram/images/`，tabbar 图标放 `miniprogram/images/tabbar/`。

## 六、文案语气

- 面向学生，口语化、简短、有温度（例："让文字继续旅行"）。
- 不暴露技术细节与审核机制（如留言审核统一提示「留言已提交，将在审核后展示」，不写"命中敏感词"）。
