# 图片资源说明

请在以下路径放置对应的图片文件：

## 必需图片
- `images/default-goods.png` - 默认商品占位图
- `images/default-avatar.png` - 默认头像占位图
- `images/bg-login.jpg` - 登录页背景图
- `images/bg-home.jpg` - 个人中心背景图

## TabBar 图标（需要 active 和非 active 版本）
- `images/tabbar/home.png` / `home-active.png`
- `images/tabbar/release.png` / `release-active.png`
- `images/tabbar/mine.png` / `mine-active.png`

> 💡 提示：可以先从网上下载任意图片重命名后使用，或者去 iconfont.cn 下载免费图标。
